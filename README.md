# IT1214-Warehouse-Inventory-System

 Project Description
This is a simple Java console-based Warehouse Inventory System.
It allows users to:
- Add items
- View items
- Update item quantity
- Delete items

 How to Run

1. Compile all files:
   javac *.java

2. Run the program:
   java Main
